# StockScout Bottom Fishing

Responsive frontend-only PWA for the Bottom Fishing mode. It never runs or copies the scoring backend. The app verifies and reads the active immutable Bottom manifest, screener sidecar, detail assets, and chart shards published by StockScout Unified.

Owner watchlists, saved screens, drawings, and alerts use the same allowlisted Supabase project as Unified. Market data and scores are EOD context, not live prices or financial advice.
